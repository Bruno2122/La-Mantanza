Resumen general

El programa está dividido en dos archivos:

- `juego.py`: controla el flujo principal del juego.
- `funciones.py`: contiene funciones reutilizables para dibujar, mover al jugador, cargar imágenes y controlar vidas.

La biblioteca principal es **Pygame**, que permite crear la ventana, dibujar imágenes, detectar teclado y mouse, y controlar el tiempo del juego. **OpenCV** se usa para reproducir el video del menú.

## 1. Importaciones

```python
import pygame
import sys
import cv2
import funciones as fn
```

- `pygame`: ventanas, imágenes, teclado, mouse, rectángulos y gráficos.
- `sys`: permite cerrar correctamente el programa con `sys.exit()`.
- `cv2`: reproduce el video del fondo del menú.
- `funciones as fn`: importa `funciones.py` usando el nombre corto `fn`.

Por ejemplo:

```python
fn.crearjugador(...)
```

significa que se está usando la función `crearjugador` del archivo `funciones.py`.

## 8. Detección de daño

```python
fn.recibirdaño(jugdatos, enemigos)
```

La función revisa si el rectángulo del jugador toca alguno de los objetivos:

```python
jugdatos["rect"].colliderect(objetivo)
```

`colliderect()` devuelve `True` cuando dos rectángulos se superponen.

Cuando hay colisión:

```python
jugdatos["vida"] = max(0, jugdatos["vida"] - 1)
```

Se resta una vida, pero nunca puede bajar de cero.

También se utiliza:

```python
if ahora - jugdatos["ultimo_daño"] < 1000:
    return
```

Esto da un segundo de invulnerabilidad después de recibir daño. Evita que el jugador pierda todas las vidas en unos pocos frames mientras permanece encima del bloque.

## 10. Límites del mapa

```python

```

Define la zona vertical donde puede caminar el personaje.

```python

    rect.bottom = limitesuperior
```

Usa `rect.bottom`, es decir, los pies del personaje. De esa manera, el límite superior se calcula tomando como referencia los pies y no la cabeza.

También se evita que salga por los lados:

```python

```

## 11. Animación del jugador

```python
if mov:
    jugdatos["frame"] = (jugdatos["frame"] + 0.15) % 4
else:
    jugdatos["frame"] = 1.0
```

Cuando el personaje se mueve, cambia de frame para crear animación.

El operador `% 4` hace que la animación vuelva a empezar después del cuarto frame.

En `dibujarjuego()`:

```python
secuencia = [0, 1, 2, 1]
idx = secuencia[int(jugdatos["frame"]) % 4]
```

La secuencia hace que la animación avance y luego vuelva al frame intermedio, produciendo un ciclo más natural.

Los estados principales son:

```text

```

Según el estado se ejecuta una sección diferente:

```python

```

muestra el menú.

```python

```

mueve y dibuja al jugador.

```python

```

muestra la imagen final.

```python

```

muestra la pantalla de derrota.

Este sistema se llama una **máquina de estados**. Sirve para separar claramente el comportamiento de cada pantalla.

## Preguntas que podría hacerte tu profesor

**¿Por qué usaste funciones separadas?**

Para organizar el código, evitar repeticiones y hacer que cada función tenga una responsabilidad concreta.

**¿Qué es `pygame.Rect`?**

Es un rectángulo que almacena posición y tamaño. También permite detectar colisiones fácilmente.

**¿Cómo detectas el daño?**

Comparando el rectángulo del jugador con los rectángulos de los objetivos usando `colliderect()`.

**¿Cómo funciona la vida?**

El jugador comienza con `5`. Cada colisión resta `1`. El sprite mostrado se selecciona con `5 - vida`, porque `vida00` representa la barra llena y `vida05` la vacía.

**¿Qué es una máquina de estados?**

Es una variable que indica qué parte del juego está activa: menú, juego, derrota o pantalla final.

**¿Por qué usas una superficie con `SRCALPHA`?**

Porque permite usar transparencia mediante el canal alfa y crear la capa roja sobre el juego sin borrar completamente lo que está debajo.

**¿Para qué sirve `pygame.display.flip()`?**

Para mostrar en pantalla todo lo que se dibujó durante ese frame.

**¿Qué significa `collidepoint()`?**

Comprueba si un punto, en este caso la posición del mouse, está dentro de un rectángulo.
